# Member Withdrawal API

회원 탈퇴는 인증된 사용자가 `DELETE /api/v1/members/me`로 요청한다.
요청 body는 없으며 성공 응답은 body 없는 `204 No Content`다.

## 처리 범위

한 트랜잭션 안에서 다음 처리를 수행한다.

- 회원의 북마크를 삭제한다.
- 시험 학습 세션과 제출 답안, 일별 학습 로그를 삭제한다.
- 회원 말문제 참여자와 연결된 회차 및 답안을 삭제한다.
- 공개 질문과 답변의 본문은 유지하되 작성자를 공용 익명 작성자 `탈퇴한 사용자`로 바꾼다.
- 마지막으로 이메일, 닉네임, 비밀번호를 보유한 원래 회원 행을 삭제한다.

기존 이메일은 탈퇴가 끝난 직후 새 계정 생성에 다시 사용할 수 있다. 탈퇴 전에 발급된
access token과 refresh token은 같은 이메일로 새 계정이 생성된 뒤에도 새 계정 인증에 사용할 수 없다.
신규 토큰은 이메일뿐 아니라 회원 ID에도 바인딩된다. 배포 전 legacy 토큰은 기존 계정 생성 시각보다
발급 초가 명확히 뒤인 경우에만 호환하며, 두 시각이 같은 초라 구분할 수 없으면 안전하게 재로그인을 요구한다.

## 응답

```http
HTTP/1.1 204 No Content
```

비인증 요청은 사용자 보호 API의 공통 계약대로 `401 SecurityErrorResponse`를 반환한다.

```json
{
  "status": 401,
  "code": "AUTH_REQUIRED",
  "message": "로그인이 필요합니다.",
  "path": "/api/v1/members/me"
}
```

## Google 연결과 모바일 처리 순서

백엔드는 Google refresh token을 보관하지 않으므로 Google 연결을 해제하지 않는다. 모바일은
백엔드가 `204`를 반환한 뒤에만 Google 권한 해제와 로컬 access/refresh token 및 사용자 캐시
삭제를 수행한다. 백엔드 요청이 실패하면 Google 연결과 로컬 로그인 상태를 유지해 재시도할 수
있어야 한다.
