== 말문제 빠른 풀이 API

비회원은 최초 회차 시작 응답의 `issuedGuestToken`을 보관해 이후 요청의 `X-Guest-Token`으로 전달한다.
인증 회원 요청에서는 guest token을 무시하며, 완료 후 다음 회차는 restart endpoint로만 생성한다.
