All endpoints require ADMIN authentication. Open means `RECEIVED` + `IN_REVIEW`; closed means `RESOLVED` + `REJECTED`.

== List reports

Query parameters: `statusGroup` (`OPEN` default, `RESOLVED`, `REJECTED`, `ALL`), optional `qualificationExamId`,
optional `categoryGroup` (`PROBLEM_ERROR`, `FEEDBACK`), `sort` (`SAME_PROBLEM` default, `LATEST`, `OLDEST`),
`page` (1-based, default 1) and `size` (default 20, at most 100). `SAME_PROBLEM` orders by the number of open
reports on the same problem, then `createdAt` descending, before paging. Reports without a live problem count as 0.
The response carries `pageInfo` with a 1-based `currentPage`.

== Process a report

`RESOLVED` and `REJECTED` require a non-blank `answer`; every `answer` is at most 1000 characters after trimming,
and a blank answer is stored as `null`. Saving a closed status sets `answeredAt` to now; saving an open status clears
it and keeps the submitted answer. With `applyToSameProblemOpen: true` the same status and answer are applied to the
other open reports on the same problem. `updatedIds` lists the target first.
