== v2 content snapshot

Every published subject with its problems, choices and `correctChoiceIds`. Explanations are not included.
The `ETag` header equals `data.version`; send it back as `If-None-Match` to receive `304 Not Modified`.

Problem `content` is a recursive JSON block array and may contain
`{type: "statementGroup", items: [{label, content}]}` blocks,
`{type: "table", rows: [{cells: [{content, header?, colspan?, rowspan?}]}], columnWidths?, border?}` blocks
(cells hidden by a merge are omitted; `columnWidths` are per-column pixel widths used as proportions;
`border` is `all` (default grid), `outer` or `none`, and unknown values render as `all`), and inline math
spans `{text: "<LaTeX>", math: true}`. Plain-text choice content wraps math in `$...$`.

Each choice is `{id, number, content, imageUrl}`. `imageUrl` is the choice image, freshly signed when it is a
managed image, or `null`. An image-only choice has an empty `content`. Managed image URLs (image blocks and
choice images) are hashed by object key, so a new signature alone keeps the version; adding, replacing or
removing an image changes it. `imageUrlsExpireAt` is set whenever the response contains a managed image.
