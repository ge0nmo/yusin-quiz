= Public Report API (v2)
:doctype: book
:icons: font
:toc: left
:source-highlighter: highlightjs

Problem error reports, suggestions and inquiries from the app. There is no member login: every request
carries the anonymous device UUID in the `X-Device-Id` header (case-insensitive, 36 characters with hyphens;
stored lowercase). A missing or malformed header returns `400 INVALID_DEVICE_ID` before body validation.
Unknown qualification codes return `404 QUALIFICATION_EXAM_NOT_FOUND`.

Date-times use the existing `LocalDateTime` format (ISO-8601, no time zone, server time) truncated to seconds.

== Send a report

`category` is one of `WRONG_ANSWER`, `EXPLANATION`, `TYPO`, `BROKEN_MEDIA`, `OUTDATED`, `OTHER_ERROR`
(problem errors, `problemId` required) or `SUGGESTION`, `INQUIRY` (feedback, `problemId` optional).
`content` is always a string, trimmed, at most 1000 characters; `WRONG_ANSWER`, `OTHER_ERROR`, `SUGGESTION` and
`INQUIRY` need at least 5 characters after trimming. `selectedChoiceNumbers` holds 0 to 5 distinct numbers from
1 to 5 and must be `[]` without a problem. `appVersion` (1 to 20 characters) and `platform` (`ANDROID`, `IOS`)
are required. Violations return `400 VALIDATION_ERROR`.

A problem outside the path qualification returns `404 PROBLEM_NOT_FOUND`. An open (`RECEIVED`/`IN_REVIEW`) report
from the same device for the same problem and category returns `409 REPORT_DUPLICATED`. A device that sent 20
reports in the last rolling 24 hours receives `429 REPORT_RATE_LIMITED`.

== This device's reports

Newest first, at most 100, no paging. `answer` and `answeredAt` are filled only while the status is
`RESOLVED` or `REJECTED`. `problem` is the snapshot taken when the report was sent; it is `null` for feedback without
a problem, and its `id` becomes `null` when the problem is deleted.
